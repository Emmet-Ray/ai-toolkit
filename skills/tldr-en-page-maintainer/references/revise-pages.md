# Revise Existing English Pages

Use these instructions only for a `revise` operation.

- Require the exact target path to exist in the fetched official upstream ref.
- Treat the user's requested correction, restructuring, rewriting, or polishing scope as the editing boundary.
- Read the complete page and enough current primary documentation to verify that revised wording preserves command meaning, syntax, platform scope, and behavior.
- Use current repository style and nearby English pages to improve clarity, consistency, grammar, terminology, placeholders, or organization within the requested scope.
- Do not opportunistically rewrite unrelated acceptable content. Adjacent edits are allowed only when necessary for grammar, consistency, or readability; record material discretionary edits.
- Do not add or remove behavior claims, change commands or options, or alter platform/version meaning under `revise`. If the requested revision requires any such change, disclose it and ask to reclassify the page as `update` before editing.
- Summarize revised passages by purpose for human review without attaching a full diff unless requested.

A `revise` operation is complete when requested wording or structure is clearer and compliant, documented behavior is unchanged, and no undisclosed scope expansion occurred.
