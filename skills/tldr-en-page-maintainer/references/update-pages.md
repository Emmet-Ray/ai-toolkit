# Update Existing English Pages

Use these instructions only for an `update` operation.

- Require the exact target path to exist in the fetched official upstream ref.
- Establish why the page needs a factual update, such as changed command syntax or behavior, obsolete options, incomplete high-value coverage, current documentation changes, platform changes, or an incorrect claim.
- Read the complete existing page before editing. Inspect every section affected by the change, including related examples, headings, placeholders, links, version notes, and command-family references.
- Use current primary evidence for every new, changed, removed, or behavior-affected claim. Recheck unchanged content when the discovered command change could make it stale; do not require unrelated stable examples to be rewritten merely to enlarge the diff.
- Preserve accurate and useful existing content where practical. Add, remove, merge, split, or reorder examples only when supported by current evidence and needed for a coherent, high-value page.
- Apply current repository style to changed content. Fix adjacent inconsistencies only when needed for correctness or coherence, and record material discretionary edits.
- Summarize factual changes and their evidence for human review.

An `update` operation is complete when the whole page is coherent under the researched change, every affected factual claim is supported, unaffected valid content is retained where practical, and material decisions are recorded.
